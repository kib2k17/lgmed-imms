# LGMED-iMMS logo tools

The Rising Sun logo is drawn in code, so every file in `static/img/brand/`
comes from one definition and none of them is edited by hand.

| Script | What it writes |
| --- | --- |
| `build_logo.py` | Every SVG in `static/img/brand/`: mark, favicon, app tile, horizontal, compact, stacked, login and sidebar lock-ups, in light, dark and single-colour versions. Text is converted to outlines from `static/fonts/inter-latin-wght-normal.woff2`. |
| `export_png.py` | `static/img/brand/png/`: favicons, `favicon.ico`, app icons, high-resolution PNG lock-ups, and the 1024 px sources `make_pwa_icons` reads. Renders with Microsoft Edge (headless). |

## Changing the logo

1. Edit `build_logo.py`. The mark is `sun_parts()` and `mark()`; colours are
   at the top; the wordmark is `wordmark()`.
2. Regenerate, from the project root:

   ```
   python tools/brand/build_logo.py .
   python tools/brand/export_png.py static/img/brand
   copy static\img\brand\favicon.svg static\img\favicon.svg
   venv\Scripts\python.exe manage.py make_pwa_icons
   ```

   The last step redraws `static/img/pwa/` and the Android launcher icons.
3. Commit the regenerated files. Rebuild the Android app to update its icon.

## Requirements

These are design-time tools, not part of the running system, so they are not
in `requirements.txt`. Install them into any Python:

```
pip install fonttools brotli pillow
```

`export_png.py` expects Edge at
`C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe`.

`build_logo.py` also keeps the first-round concept symbols (`concept1()` to
`concept4()`) and the earlier Pulse Shield (`shield_mark()`) for reference.
The presentation pages in `docs/brand/` are records of the design rounds and
are not regenerated by these scripts.
