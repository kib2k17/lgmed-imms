# LGMED-IMMS Module Inventory

Companion to the *System User Manual* (`system-user-manual.pdf`). It lists every module and
sub-module found in the repository, what it does, who may use it, where it lives, which
procedures and screenshots the manual provides, and what is still missing.

**Roles** — SA: System Administrator · AD: Administrator (Division Chief) · ST: LGMED Staff ·
EN: Encoder · VW: Viewer. Access was verified by signing in with each role on the
documentation instance and opening every page (403 = refused). Figure IDs refer to
`assets/figures.json`; image files are `assets/<module>/<id>.png`.
