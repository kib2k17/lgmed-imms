This runs inline and before app.js (deferred, so it executes later) purely for listener order: the first submit is held back here, stopping app.js's handlers from disabling the button and masking the password on an attempt that is not going anywhere yet. The second pass - the real one, after the token is in - runs every handler in the usual order. {% endcomment %} {% if recaptcha_site_key %} {% endif %}
